Método

Cómo trabajo

  1. Entender el proceso

    Primero el flujo real: quién carga datos, qué se decide y qué se reporta. Sin eso, el software sobra.

  2. Entregar algo usable

    Prefiero una versión que el equipo ya pueda usar a una demo perfecta que nadie toca.

  3. Dejarlo claro

    Documentación breve, acceso ordenado y cambios versionados para que no dependan de mí en cada ajuste.
